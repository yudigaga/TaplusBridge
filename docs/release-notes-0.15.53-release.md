# TaplusBridge 0.15.53

正式版 **0.15.53 / 85**，汇总公开版 0.15.51 之后的改动。

- 收到同一次有效单指手势的抬手事件、实际持按达到识别阈值后，才尝试关闭本轮新出现的来源菜单。持续按住、提前抬手或手势取消时保留菜单。
- 系统确认同一来源应用正在录音时，跳过宿主首次识别呈现和长按拖动准备及触摸交接。录音状态未知或查询超时时沿用普通流程，独立的抬手后补点沿用原规则。
- 系统观察到配置失效、新输入或手势取消后，撤销旧手势的菜单操作资格，避免恢复配置时误执行旧操作。
- 跨进程交付日志区分未连接、已收到回复和结果未知。结果未知时避免自动重放。

覆盖安装后请重启手机，确认 LSPosed 的传送门／内容扩展和系统框架作用域均加载 `0.15.53 / 85`，然后打开模块确认系统配置。

该构建的归档记录包含 1,957 项 Android 单测、73 项 Python 测试，Release lint 为 0 错误、32 条警告。真实录音、ROM 弹窗和触摸交接仍需真机验收。
