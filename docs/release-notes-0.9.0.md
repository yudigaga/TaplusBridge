# taplusbridge 0.9.0

- 新增「生效应用」，可二选一使用黑名单或白名单，支持应用图标、搜索和多选。
- 两份名单分别保存；首次保存才接管传送门的应用范围。空黑名单允许所有应用，空白名单全部禁止。
- 接管系统长按触发前读取的有效名单，以及宿主创建识别浮窗前的应用范围检查；保留原有手势、页面和抓取能力限制。
- 冻结模块本体时继续读取框架配置；安装与卸载应用后重算白名单补集。
- 名单由主用户统一管理，不覆盖宿主原始名单文件；保存后来源应用可能需退出重进以刷新缓存。
- 兼容传送门 4.1.3 / 40013、5.1.5 / 50015；526 项 JVM/Robolectric、22 项 Python 测试通过。真机 Hook、跨用户枚举和缓存刷新待验证。
