# 0.15.22 长按拖动移交原因诊断候选

> 本文中的本地归档路径不随源码仓库分发；公开发布产物请以 Releases 为准。

日期：2026-11-05（Asia/Shanghai）
版本：0.15.22 / 54。仅本地签名候选，未安装或发布。

## 目的

0.15.21 的日志把宿主窗口更新失败、system_server 窗口预检拒绝、InputManager API 不存在、API 返回 `false` 等不同情况都压成 `IllegalStateException`。本版把失败点改为固定原因码，供下一次 LSPosed 日志定位。

本版是诊断构建，**不代表已修复设备上的拖动**。真实拖动仍要在目标 ROM 上验证。

## 变更

- system_server 记录固定的窗口拒绝原因、`input_api_missing`、`input_transfer_rejected` 或 `input_transfer_exception`。
- 宿主分别记录遮罩添加/更新失败、Runtime Binder 不可用和系统未接受移交。
- 异常正文、窗口坐标、包名、手势令牌、消息文字及链接不写入新诊断字段。
- 移交失败仍然 fail-closed；只有系统确认移交成功后才启用拖动期间的手势门控和震动。
- 归档分析器支持新 `reason=` 字段，同时兼容旧版异常类日志；未知原因映射为 `unknown`。

未采用 HyperPortal 的 AES 来源端拖拽作为本版实现：项目记录的设备组件为 ContentCatcher 4.1.4 / OS3_1，而 HyperPortal 补丁目标是 AES 5.1.7；本地没有对应设备 APK 可做重打包验证，且项目当前范围不包含替换系统 ContentCatcher 或注入来源应用进程。
