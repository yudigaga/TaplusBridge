# 0.14.5 / 30：完全匹配重复控件

日期：2026-11-02（Asia/Shanghai）。根据用户最新截图修正完全匹配页仍显示 Google 模式栏的问题，递增版本并构建本地 R8 Release。延续用户此前要求，不运行回归测试或操作手机；未远程发布。

## 问题

0.14.4 通过固定向上裁切隐藏视口最顶端的 Google 搜索／筛选栏。最新截图显示完全匹配页的 Google 模式栏位于上传图片预览下方、无结果提示上方，不在裁切区域内，因此仍与传送门上方的原生模式栏重复。传送门输入框本身已连接当前图片的 refine 会话，不会重新上传。

## 修正

- 对 AI／完全匹配页面按可见控件文字识别 Google 自带「AI 模式／全部／完全匹配／外观匹配」横向模式栏以及「添加更多搜索条件」搜索控件，隐藏其最小可见容器。
- 使用限频 MutationObserver 处理 Google 页面异步更新后的控件重绘，不依赖易变的私有 CSS 类名。
- 打开右上角「原网页」时先恢复页面原控件；返回内嵌结果后重新应用隐藏规则。停止固定像素裁切，避免切掉正文。

Google 的真实回答、匹配结果和上传图片预览保留在同一 WebView 中；传送门顶端输入与模式继续作为唯一的重复搜索入口。若 Google 改变标签文案或页面结构，文字定位可能需要调整。
