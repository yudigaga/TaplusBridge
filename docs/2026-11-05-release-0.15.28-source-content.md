# 0.15.28 真实源内容与稳定补点

日期：2026-11-05（Asia/Shanghai）。版本：0.15.28 / 60，本地长期签名 Release。分析证据见 [HyperPortal 对照报告](2026-11-05-hyperportal-source-content-report.md)。

## 用户可见变化

- 增加可选平台页面结构采集：识别阶段优先获取原窗口触点附近的实际文字与链接；真实链接已取得时无需再次补点。识别、拖动共用同一 physical DOWN 的结果，没有逐应用分支。
- 普通文字使用独立 content 载荷，不再要求文字本身必须是一个网址。已有原生标题、图像与后取得的实际正文合并在同一轮；空原生回调不覆盖已经准备的正文。
- 遮罩接管前源应用已收到超过 touch slop 的移动时，撤销后续原点补点，避免滚动后的原坐标指向其他卡片；返回原位也不恢复。接管后的模块拖动保持可用。
- 原生取链移交之后仍保留移动证据；真实新 DOWN 同步撤销旧正文票据，取数据还检查手势代次。合成拖动/截图几何不能再授权新的源点击。
- 修复滚动卡片裁剪坐标、同手势毫秒换算误差、结构响应等待与重复识别阶段延迟；新增只含固定阶段的结构采集诊断。

平台结构接口为可选能力：应用或 ROM 不提供结构、结构为空、窗口不匹配、密码/编辑输入、未知变换、自绘内容等仍可能无法直接取数；现有截图与补点开关、secure/输入法/来源范围限制继续生效。没有替换 ContentCatcher 或增加来源 Xposed Hook，不能把本地测试当作所有应用覆盖率。
