## 回归与审阅

先在旧实现观察到真实失败，再实施修改：内存已更新后的磁盘提交失败/抛错、被提交阻塞的发布读取、同步回调重入、等待恢复的旧 Lens 工作线程、同图换查询时旧下载排队、持续滴流响应、输入慢检查与新 DOWN 并发、慢 Binder 移动突发及触边后向内松手。

独立审阅发现并修正两类集成问题：

- 配置回调在提交返回前读取旧的已确认值，UI 改为合并并延后到主线程下一次消息刷新；成功及失败后的显示均在提交结果确定后更新。
- 轻量 MOVE 响应与合并队列仍须维护“最后触边”语义，不能丢掉随后向内移动覆盖的触边点。

SDK 28 界面测试还暴露 ContextCompat 动态接收器权限模拟差异；包事件改用 API 33+ 平台非导出注册，旧版使用仅含受系统保护包事件的平台注册，未新增权限。

Robolectric 的 ParcelFileDescriptor pipe 为普通文件，无法据此宣称验证了真实内核管道。阻塞/总时限使用关闭可解除的受控 Java 流验证；并核对本机 Android SDK 的 FileInputStream/FileOutputStream 关闭实现会调用 `IoBridge.closeAndSignalBlockedThreads`。ROM 和真实 Binder/FD 生命周期仍需手机验收。
