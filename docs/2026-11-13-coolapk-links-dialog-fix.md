## 实现

- `ScopeCaptureWindow` 接受同 Activity、UID、用户的主窗、普通 Dialog 和直属 Popup。快照记录实际按中窗口的 surface、bounds，并保留主窗身份。弹层长按可读取弹层本身；截图、触摸转移使用实际目标窗口。主窗替换、陌生父窗、其他应用、安全窗口、输入法及窗口变化仍拒绝。
- `SourceWindowAccess` 区分 DOWN 时已经选中的弹层和随后出现的遮挡菜单。原始弹层本身可补点；新增模态菜单可在所属主窗内选择菜单之外的区域，确认外侧几何命中仍为同页主窗或该菜单，仅发送 DOWN/CANCEL 关闭遮挡，再复验主窗后点击原始位置。不使用返回键；没有可证明的外侧区域或菜单没关闭时停止。系统几何查询与模态输入分发不同，测试覆盖两种合法几何命中及其他应用遮挡时拒绝。
- `HostProbeWindow` 在临时穿透期间同时设置 NOT_TOUCHABLE、NOT_FOCUSABLE，结束后恢复原 flags/alpha。该修改避免可聚焦宿主面板继续占用焦点；本归档不足以证明它是所有失败的原因。
- `HostLongPressDrag` 以原子认领区分真正启动的原生探针与系统兜底；仅具备几何条件不再阻止兜底。原生已认领后系统不重复补点；系统已请求后原生不能再启动；开始导入后不接纳晚到认领。
- 浏览器启动逻辑保持现状，增加单网址只启动一次、选择期间目标消失的回归验证。
- 全量检查发现日志分析器隐私测试会因归档 SHA-256 偶然包含三位坐标字符串而误报；测试只对实际元数据检查坐标泄露，排除摘要字段，生产分析器未改动。

## 手机复测

1. 覆盖安装候选 Release 包。保持 LSPosed 的传送门和系统框架作用域，重启手机，再打开模块等待系统确认配置。
2. 开启“长按取链接”；需要图三弹层截图识别时，同时开启“截图识别兜底”。保持原应用名单允许酷安。
3. 在图一“查看链接”的实际文字上长按；在图二 GitLab 卡片上长按后拖向浏览器。应得到实际 URL；只有标题时不能声称取链成功。
4. 先打开图三底部分享弹层，在弹层文字上长按，验证识别触发和内容范围；再验证关闭弹层后的普通长按仍可用。

本地 JVM 无法验证酷安真实点击、系统输入分发、ROM 触摸转移和真实浏览器行为。E6 对应“点击已送达但没有启动网址”的分支未能在设备上定位，不保证本次已覆盖所有“查看链接”失败。若仍复现，须使用候选版本的新日志继续区分补点未命中、菜单未关闭和应用内部导航。
