# 0.15.30 补点开关与拖动菜单

日期：2026-11-05（Asia/Shanghai）。版本：0.15.30 / 62，长期签名 Release。本轮作用域保持 `system` 与 `com.miui.contentextension`。

## 用户可见变化

- “手势设置”新增明确的“补点取链”总开关，控制长按识别与长按拖动的补点。复用原 `scope_link_probe` 保存值，未保存过则默认关闭；与手势配置同一次提交。拖动关闭时仍可调整补点，开启后才显示补点说明。
- 应用页移除原“长按取链接”同义开关，只保留应用范围与截图兜底；保存应用名单不再携带补点草稿，避免覆盖手势页刚保存的选择。原生链接、Assist 结构和截图 OCR 保持独立。
- 普通原生取链补点、系统识别及拖动补点统一受控。补点与人工观察的能力票据分开；关闭后取消补点，Provider/System 授权、READY 延迟及注入前复核当前配置，避免只改页面文字而后台仍自动点击。
- 按住后的四向浮层采用现有 Miuix 明暗配色，收敛彩虹颜色，统一圆角透明预览、动作图标及文字底板；保留既有命中几何、触摸接管、震动和松手动作。
- 松手后的内容、链接、浏览器及自定义分享目标选择统一使用 Miuix。保留候选一点执行、单种内容直接执行、URL 单选和内容默认全选；列表可滚动，取消/执行固定可用，全部取消后执行按钮禁用。系统分享选择器仍由系统呈现。
- 保存失败提示在拖动关闭时也可见，避免补点草稿与实际配置不一致却没有反馈。

## 验证

最终 43 套定向 Java/Kotlin 测试共 642 项全部通过，0 失败、错误或跳过；52 项日志工具测试通过。覆盖关闭后的新授权、已发行能力撤销、最终输入授权、人工观察保留、配置同事务保存、应用名单保值、选择与取消、返回、空选禁用、长内容、紧凑大字号及明暗主题。旧实现的 3 项 UI、9 项门控及错误提示缺口均有实际失败记录。

新选择页最初缺少 Miuix 弹层的 Scaffold host，已补透明 Scaffold 并重验 12 项菜单测试。联合测试暴露已有 PNG 管道测试的提前 EOF：本机 Robolectric 4.14.1 用普通临时文件模拟 pipe，因此测试增加单线程写入队列屏障后再读，不修改生产管道，也不通过 sleep、异常吞掉或读取重试掩盖失败。

已检查真实 Robolectric native-graphics 浅色、深色、紧凑大字号的菜单图，以及手势开关与四向浮层图。Release lint 为 0 错误、39 条警告。最终构建和签名/对齐证据见 `artifacts/validation-0.15.30.json`。

## 使用与边界

安装后重启，使系统和传送门进程载入新 Hook；在“手势 → 补点取链”切换并点“保存”。开关不改变既有作用域和截图兜底设置；关闭补点时仍可使用原生、结构及 OCR 识别，但不会因此产生原本拿不到的链接。

框架配置沿用现有异步发布机制，约 100ms 合并更新；不承诺跨进程瞬时原子生效。浮层透明材质为主题配色、渐变、细描边与阴影，不宣称实时背景模糊或光学折射。
