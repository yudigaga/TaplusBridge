## 实现与新版差异

- `HostPolicy` 仅允许 `(4.1.3,40013)` 与 `(5.1.5,50015)`；名称和代码交叉、相邻版本及空名称均拒绝。
- `BridgeProvider` 改用统一策略；Hook、识别、设置页和冻结本体的系统通道已使用相同策略。保留原同用户、宿主 UID、规则匹配及一次性票据约束。
- 宿主版本日志按实际版本输出；归档诊断工具同时识别新旧事件。
- `verify_host.py` 补入原先遗漏的 `Entity.getEntityClass/getEntityStr`，每版共检查 60 个真实定义和 static 标记。
- `AppsUtils`、`TaplusRecommendAdapter`、`TaplusRecommendBaseCard`、`TextRecommendationInfo`、`SourceIcon`、`TextRecommendationUtils` 和 `RecommendationMonitor` 的两版导出一致。剪贴板差异仅为反编译生成的类名；OCR 增加已回收 bitmap 的保护。
- 新版 `cancelTask/onDestroy` 加强 disposable、bitmap 与浮窗清理。模块先取消本轮探测和异步任务，再放行宿主清理，现有顺序兼容。
- `BaseFloatView.addToWindow` 新增悬浮窗权限检查；未授权导致没有可用宿主窗口时，模块保留拒绝探测行为。
- 新增 `mNavBarDimView` 为 TYPE_PHONE 的导航栏高度窗口，flags `0x1000328` 不含 NOT_TOUCHABLE。模块仍只管理原有两窗；如果它遮挡触点，系统来源窗口检查会拒绝。底部卡片与不同导航模式的实际表现待设备验证。
- `collect_validation.py` 增加 Release 模式，分别读取 Release lint、正式版本及长期证书；默认 Debug 模式保留。
