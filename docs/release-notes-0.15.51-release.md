# taplusbridge 0.15.51

正式版 **0.15.51 / 83**，基于上一正式版 0.15.50。

- 修正来源本轮新弹窗的关闭时机：只有模块长按识别或后续拖动阶段到达后，才按原安全检查尝试关闭；系统原生长按阶段保留。
- 识别界面提前显示时等待真正的识别阶段；提前松手会撤销候选，之后不补发关闭。
- 使用真实输入事件的释放时刻判断持按，避免输入派发或后台处理延迟被算作额外持按时间。

三段手势的配置时长不变，长按前已有窗口继续保留；来源、窗口、配置、物理输入和按键撤销检查继续生效。没有增加模拟返回或盲点点击。

覆盖安装后重启，保持传送门／内容扩展与系统框架作用域启用，再打开模块确认系统配置。实际 ROM 弹窗回调与关闭效果仍需手机验收。

详见[阶段边界说明](2026-11-14-popup-stage-boundary.md)、[使用指南](usage.md)与[构建和发布核验](2026-11-14-release-0.15.51.md)。
