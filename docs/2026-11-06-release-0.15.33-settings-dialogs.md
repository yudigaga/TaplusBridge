# 0.15.33 手势与应用弹窗收纳

日期：2026-11-06（Asia/Shanghai）。版本：0.15.33 / 65。长期签名 Release。

## 界面调整

手势主页保留拖动、补点开关与系统状态，识别通道、阶段计时、方向动作、分享菜单通过摘要入口打开 Miuix 弹窗。拖动关闭时隐藏其计时、方向和分享入口。弹窗正文单独滚动，完成按钮固定在底部。计时标签与数值增减分行，适应窄屏与大字体。

方向动作使用同一弹窗切换子列表，选定后返回四方向。系统返回顺序为动作子列表、方向列表、手势页、首页。整个 Overlay 按分组和方向建立 composition key，子列表返回时重建内部动画状态，避免已完成的预测返回动画残留。

应用主页只显示当前黑名单或白名单中已勾选的应用。点击“添加应用”打开搜索弹窗，只列未选候选，勾选后移入主名单；主名单取消勾选则移出。未安装或不可见的已选记录保留并可删除。切换模式仍保留两份独立名单。

识别通道、截图兜底、Lens、补点开关继续点击立即保存、回读并同步。计时、方向、分享与应用名单继续使用页内草稿，点击顶部保存后生效；完成或关闭弹窗保留草稿，顶部放弃恢复已保存值。即时保存失败也在弹窗内显示错误。
