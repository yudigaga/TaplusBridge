# 替换翻译

入口：识别 → 替换翻译。弹窗内单独保存，不受“保存手势／放弃手势”影响。需要开启概览的应用流转、保持模块本体可用；已知来源按应用名单判断。传送门剪贴板翻译没有来源包名，仍要求同用户、受支持传送门UID认证。

## 使用本机翻译应用

选择“本机翻译应用”，再选择已安装应用提供的入口。优先使用专用翻译，其次文字处理；分享兼容入口只承诺把文字交给目标应用，不保证直接进入翻译页面。列表可按名称或包名搜索，并标明入口类型。

谷歌翻译、有道等是否出现在列表及其接收文字后的行为，取决于手机安装版本声明的标准入口，不能只凭应用名承诺兼容。目标语言由目标应用设置。选择后点击弹窗“保存”。已保存组件不可用时不会改发给其他任意应用。

## 使用 AI 翻译

选择“AI 翻译”，填写以下内容：

- 完整HTTPS Chat Completions接口地址，例如默认完整地址所示；不会自动追加路径。
- API Key：填写原始密钥，无需添加Bearer前缀。已保存密钥不会回显，留空保留旧值；清除需显式操作并保存。
- 模型名称：由所使用服务提供。
- 目标语言：默认中文，可改为所需语言。
- 翻译提示词：可展开编辑，留空则使用默认要求。

“测试连接”使用当前草稿发送固定句子“Hello, world.”，不会保存配置或发送当前选中文字。保存后，传送门翻译按钮、翻译卡片及拖动翻译使用同一设置。AI结果在模块内显示，可选择文字、复制、关闭；失败可显式重试，不会自动改发给另一个服务。

修改服务、密钥、方式、流转开关或来源权限后，旧结果任务不再使用旧配置重试，需要重新选择文字。关闭结果页会取消请求；旋转保留同一内存任务，不将正文或密钥写入实例状态。

## 关闭替换与边界

选择“沿用传送门翻译”并保存。模块不可用、应用流转关闭或交接前条件不满足时保留原宿主流程。配置进入AI模式后的服务请求失败，会在模块结果页报错而非静默使用原服务。

首版仅支持文字输入。原文或OCR识别文字可以翻译；只有图片而没有文字时仍保留宿主OCR到翻译的现有链路。正文上限32768字符，AI响应上限1MiB，网络总期限30秒，不自动重试，不跟随携带凭据的HTTP重定向。服务返回截断、过滤或工具调用结束状态时，不把片段当作完整译文。

API Key和完整配置只保存在本体私有偏好文件，不进入系统运行快照、远端偏好、宿主IPC、日志或启动Intent。启动Intent只有短期一次性token；交接票据中的原文最多暂存内存30秒，过期或进程死亡后失效。消费后的翻译任务在结果页存活期间保留重试所需原文，不写入磁盘或实例状态。

冻结模块本体后，新的本机/AI替换翻译不可用；不会将AI密钥下发到系统来维持冻结运行。LSPosed作用域仍只要求系统和传送门。

本地测试使用模拟应用和HTTP连接，未请求真实AI服务，也未在手机验证谷歌、有道及宿主Hook行为。
