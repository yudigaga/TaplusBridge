# taplusbridge 0.11.0

- 「生效应用」新增默认关闭的「长按取链接」，与名单、截图兜底一起保存；升级保留原有设置。
- 开启后，真实长按松开自动点一次原位置，在网页 Activity 启动前截获 HTTP(S) 地址，通用处理支持的系统启动路径。
- 链接作为补充，与本轮原文、图片及原生操作共存；由用户选择执行操作，不会因链接成功丢弃其他内容。
- 取链期间暂存原生图文，避免先弹出的原生界面遮挡点击；取链失败仍可交付原有内容。截图继续受原开关控制。
- 真实新触摸、名单/配置变化会撤销旧探测；注入最多一次点击。延迟网页启动在有界同源窗口内拦截，URL 不写入诊断日志。
- 仍只需传送门、系统框架两个作用域。保留宿主隐私检查和后台回调；无应用名、标题、网址硬编码。
- 85 项 JVM、2 项诊断工具定向验证通过，两版宿主各 77 项 DEX 定义契约通过；正式构建与长期签名、对齐另留产物记录。完整测试、完整 lint 和真实设备效果尚未验证。内部导航、非 HTTP(S)、PendingIntent、长按菜单遮挡及其他未覆盖入口不保证取链。
