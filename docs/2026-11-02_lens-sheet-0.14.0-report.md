# 0.14.0 独立识图结果页

日期：2026-11-02，Asia/Shanghai。版本：0.14.0 / 25。用户界面授权见 [scope.md](scope.md) 的本次追加记录。

## 当前行为

未点击「识图」时保留原传送门图片面板。点击后自动识图并打开独立浮窗：初始为底部半屏，上方显示当前图片大预览，向上拖动展开全屏。默认结果使用 Android 原生双列瀑布流；点击条目在结果页内浏览来源网站，返回时恢复缓存的原生结果。

搜索栏与「AI 模式／全部／完全匹配／外观匹配」复用已取得的真实 Lens 图片搜索地址，不重新上传。默认「全部」且输入为空时显示原生结果；其他查询与模式加载 Google 实际页面，AI 回答由 Google 提供。返回原生结果会恢复「全部」、清空附加查询并恢复本轮原始搜索地址。右上角「原网页」只有取得真实地址后才可用，用户点击才打开外部浏览器；高级模式下指向当前派生的搜索页。

## 窗口、输入与清理

结果页使用独立 Dialog，继承当前宿主根窗口的实际 `WindowManager.LayoutParams.type`，成功显示后才暂时隐藏原根 View。传送门 5.1.5 的静态依据是 `TaplusMainFloatView.initWindow()` 使用 2002；代码从运行时窗口读取类型，不为其他环境假定固定值。原图片容器不插入结果控件，也不移走原有子 View。关闭结果页后恢复原窗口可见性；识图请求完成只结束后台任务，不提前恢复或关闭仍在浏览的结果页。

返回键先处理内嵌网页导航或返回原生结果；全屏状态可收起，半屏可关闭。输入法和系统栏参与结果页布局。宿主原有键盘广播会结束识别任务，因此仅在有效结果页自身搜索框或网页持有输入焦点时豁免这一路退出；Home、无关应用切换、换图、宿主关闭和配置变化仍按原路径清理。关闭网页前隐藏其输入法并清除焦点，随后移除、销毁 WebView。关闭或换图同时使旧任务、旧地址和回调失效，不回收宿主持有的图片。

初始焦点由页面容器持有，避免搜索框自动抢焦点而跳过半屏。Google 验证期间暂时隐藏自身窗口时，保留逻辑显示状态，避免依赖 `Dialog.isShowing()` 的可见性结果而重复建窗；显式关闭同步完成幂等清理。普通点击交给 LinearLayout，额外触摸分支只处理拖动；WebView 内的手势按本窗口内实际位置交给网页。

| 依据 | 结论 | 实现路径 |
| --- | --- | --- |
| 两版已提供宿主的静态调用链 | 「识图」接管原图片操作，原面板在点击前保留 | `PortalLensHooks` → `PortalLensPanel.search()` |
| 当前根窗口参数与独立 Dialog | 半屏／全屏结果页与原图片容器分离 | `LensResultSheet`、`ensureResultSheet()`、`closeResultSheet()` |
| 本轮真实结果 URL 与受限模式映射 | 查询只修改文本与模式，保留图片会话参数 | `LensSearchUrl` → 结果页内实际 Google WebView |

## 会话与验证边界

自动上传和后台解析沿用 [0.13.0 的实现与实网证据](2026-11-02_lens-auto-0.13.0-report.md)。普通识图不经过网页文件选择器，也不自动打开 Activity 或浏览器；只有实际 Google 确认／验证页才提供显式处理入口。

高级模式的宿主 WebView 与模块 `:lens` 工作进程使用不同 Cookie 存储。这里复用的是图片搜索 URL 上下文，未同步账户、登录或验证 Cookie，也不继承 Chrome／Google App 会话。Google 实际是否展示 AI 内容、确认或验证页面，以所加载网页为准；不能将控件可点击当成高级模式已在目标手机成功返回内容。
