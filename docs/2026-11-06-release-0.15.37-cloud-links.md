# 0.15.37 / 69 网盘入口和协议规则

本版扩展磁力、ed2k 的识别与规则流转，并加入独立的「网盘链接适配」开关。位置为「规则 → 打开行为」，切换即时保存和同步；关闭后保留原 HTTP(S) 网址，磁力和 ed2k 仍按协议规则处理。覆盖安装后重启，使系统与宿主运行相同版本。

## 配置方式

在规则编辑器选择目标应用，匹配条件填写 `magnet:` 或 `ed2k:`。也可以粘贴完整有效链接，保存时仅存协议匹配键。来源限制、应用开关、安装检查和歧义处理继续生效；未命中规则的协议链接不能借原生候选绕过规则。没有写死 115 为默认目标。

网盘网页适配同样先由规则选择目标，再决定是否转换。磁力仅规范协议头为小写，哈希、名称和参数保持原样；ed2k 原始竖线分隔和有效扩展保留。文本、HTML、CDATA、原生卡片、补点捕获、识别结果和拖动复用同一验证器，继续保留各来源开关及同会话约束。

## 当前适配范围

| 网盘 | 接收方式 | 适配边界 |
| --- | --- | --- |
| 123 | 官方 `pan://umeng.com/share/list` 业务入口 | `share.123pan.cn` 及其子域的 `/123pan/`、`/s/`、`/ps/` 单一分享标识；支持 URL `pwd` |
| 百度 | 官方 `bdnetdisk://n/action.SHARE_LINK` | `pan.baidu.com/s/1KEY`，保留短分享标识和 `pwd` |
| 阿里 | 官方 `smartdrive://share/browse` | 已核官方域名的 `/s/ID`，本版仅无 query/fragment 的链接；客户端仍可要求输入提取码 |
| 夸克 | 浏览器 `qklink` / 独立网盘 `qkcloudlink`，内层官方 Flutter 分享路由 | `pan.quark.cn/s/ID`，两层编码传递分享标识和 `pwd` |
| 115 | APK 自有 `oof.disk://url/` | 指定生产分享域，完整原网址在应用内浏览器打开；不等同原生导入 |
| 迅雷 | 官方 `xunleiapp://xunlei.com/webview` | `pan.xunlei.com/s/KEY`，完整原网址在应用内 WebView 打开 |

123、百度、夸克遇到未适配的文件/目录参数、重复密码或 fragment 时保留原网址，避免改成根分享而丢失目标。阿里未证实 URL 提取码字段的页面也保留原地址。天翼、微云及其他未核实网盘沿用原网址接收能力，不能称为全部网盘均已适配。没有通过启动主页、发帖或上传文本来冒充分享页打开。

## 证据与实现

- [115 APK 接收契约](2026-11-06_reverse-115-link-contract-report.md)：磁力/ed2k 实际进入离线添加页面；SEND 会发帖，因此不作打开回退。
- [123、百度、阿里、夸克官方页面证据](2026-11-06-cloud-open-multi-source-report.md)：公共页面与静态脚本，只读定位唤起格式，不请求分享文件。
- [ULink 参数边界](2026-11-06_reverse-ulink-ukid-report.md)：官方 SDK 1.2.0 / 2.0.0 的业务回调不以动态 `_ukid` 为必要条件，模块离线构造固定业务字段，不请求服务器生成用户分享 URI。
- [115、迅雷及未适配站点](2026-11-06_reverse-cloud-web-open-contracts-report.md)：说明应用内浏览器语义及天翼、微云缺少静态入口的限制。

生产入口统一位于 `bridge/CloudLinkHandoff.java`，由 `LaunchPlanner` 在规则匹配后使用。总开关通过 RuntimeSnapshot schema 7 发布，框架只读该快照；开关变化导致配置 identity 改变，旧票据与采集结果失效。旧 schema 1–6 不包含此开关时按关闭迁移。
