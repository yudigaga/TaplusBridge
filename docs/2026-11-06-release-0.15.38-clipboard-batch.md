# 0.15.38 / 70 剪贴板入口与批量下载链接

剪贴板收到网址、磁力或 ed2k 后，现在独立生成与长按相同规则体系的目标入口。单条入口直接按规则流转，同目标多条聚合为带数量的入口，进入模块选择页。拖动菜单中的下载链接也支持多选、全选；网址继续一次选择一个。没有增加来源应用作用域，没有新增后台剪贴板读取服务。

## 使用方式

先在「识别」中开启剪贴板识别通道，并在规则页配置域名或 `magnet:` / `ed2k:` 对应的目标。剪贴板来源视为未知，只使用通配来源规则，不能继承前一个长按应用的来源。传送门自己的剪贴板、隐私确认及镜像来源等前置保护继续生效。

复制多条磁力后，选择带数量的目标卡片，勾选需要的项目或全选。多个规则目标分组显示，只有所选目标组参与本次操作；未匹配或冲突规则不会被擅自归入其他应用。不支持批量的目标提供明确提示和由用户点击的“复制已选链接”。不会用文本分享、发帖入口或循环打开应用来冒充批量添加。

本版已核实的真正批量接收器是用户提供的115 37.2.6。其 `oof.disk://lx/` 支持多行内容，经应用自己的确认弹窗进入离线添加页面；仍由用户确认提交。该入口依赖已登录且已创建的115主页接收者，因此界面明确提供“打开应用并登录”“已打开，批量添加”“复制已选链接”。先进入115主界面完成登录，返回后再继续；模块不定时盲发，不自动提交。

识别结果数量上限从8提升到64条，原始识别文本仍限制128KiB。提交批次最多64条、总文本24KiB，编码后URI最大32KiB；过界整批拒绝并提供复制，不悄悄提交前几条。普通单条仍使用现有规则、网盘适配开关和解冻流程。

## 会话与内容保存

- 剪贴板增强拥有独立会话，不借长按的 epoch 或拖动数据。
- 服务、具体浮层、当前文本、配置 identity、异步服务器任务均关联本轮；旧任务不能更新新复制的内容。
- 浮层创建完成或已显示浮层收到新复制后才发布，本地规则入口不依赖网络 NER。
- 关闭剪贴板通道、配置变化、浮层销毁和开始长按时，旧入口失效。已失效的本地卡片有弱引用标记，排队点击不能降级为普通推荐。
- 模块选择页只接受经已认证宿主申请的30秒单次内存 token，公开 Intent 不带原文。选择页中的内容最多保留5分钟且每次操作重新检查配置。
- 剪贴板及识别批次的临时流转使用内存票据，目标需要解冻时也不将批量原文写进磁盘票据。

模块被冻结时，原有单条系统独立流转保留；新增的多链接模块选择界面需要模块可运行。无法打开该界面会明确提示，不绕过冻结、不通过 Provider 强制唤醒模块。

## 实现与证据

剪贴板实际链路由本地传送门4.1.3及5.1.5源码确认：原先 clipboard_data 虽可被收集，但本地长按发布器没有激活剪贴板视图，原 NER 还会为非HTTP文本强加 `http://`。新 `HostClipboardLinks` 在专属浮层准备后发布规则模型，只清理其推荐卡片，不移除编辑、电话/位置或设备卡片。只有全部链接已被本地入口覆盖时才抑制重复整段URL NER。

批量接收的完整 APK 调用链与非 sticky EventBus 限制见 [115批量入口报告](2026-11-06_reverse-115-batch-contract-report.md)。通用批次规划位于 `BatchLinks` / `LaunchPlanner`，选择页能力位于 `LinkChoiceRequests` / `LinkChoiceActivity`，拖动界面复用既有 Miuix 多选组件。
