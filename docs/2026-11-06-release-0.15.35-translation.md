# 0.15.35 本机与AI替换翻译

日期：2026-11-06（Asia/Shanghai）。正式Release：0.15.35 / 67。

## 功能

识别页新增“替换翻译”弹窗，模式为沿用传送门、本机翻译应用、AI翻译。默认沿用原翻译；配置独立显式保存，关闭或保存手势不提交翻译草稿。切换模式保留另一路参数。密钥框不回显已保存值，留空保持旧值，清除需显式保存。

本机模式发现标准TRANSLATE、PROCESS_TEXT及文本分享入口，按组件与动作保存，排除模块/宿主回环、不可导出、不可访问及停用目标。选择界面区分专用翻译、文字处理、分享兼容，不以应用名伪造适配。实际发起前重新核对目标，交接不完整时保留原宿主流程。

AI模式提供完整HTTPS Chat Completions地址、密钥、模型、目标语言与提示词。系统要求和用户原文分别放入system/user消息，不自动拼地址或重试，不跟随重定向；响应限制1MiB、正文32768字符、30秒请求期限。空回复、截断/过滤/工具调用结束状态不当作完整译文。测试连接使用固定短句与当前草稿，不保存设置或发送选中文字。

AI译文使用Miuix结果弹窗，纯文本可选择与复制，错误可显式重试。关闭取消signal/future并拒绝晚到结果；配置、总开关或来源权限变化后，旧任务在入队、执行与回包前失效，不请求旧服务。旋转保留内存任务，不将正文或密钥序列化。

使用方法：`docs/2026-11-06-translation-usage.md`。

## 宿主接管与边界

在本地4.1.3/40013和5.1.5/50015源码、smali中核对：`TaplusRecognitionExpandedTextCard.doTranslate()`使用`mSegmentAdapter.getSelectedWords()`自然选中文字；卡片自身同名getter的`||`分词串不可作原文。拖动原翻译按钮最终走同入口。翻译推荐卡还可能直接调用`AiWindowUtilsKt.startAiWindow(Context,String)`，三个调用点均属翻译，该精确方法一并接管。原AppsUtils推荐路由在翻译分支创建交接Intent，不重复挂第二生成Hook，不改推荐卡正文或服务端数据。

宿主只有在Provider按同用户、受支持版本与宿主UID认证后才能申请票据。Intent仅包含43字符随机token，票据内存保存、一次消费、30秒失效、容量16，消费时复验配置身份和来源。已知来源查应用名单；剪贴板没有来源包名，仅允许已认证宿主显式翻译。API Key及完整配置仅在`translation_private`私有文件，不进入RuntimeSnapshot、框架远端偏好、宿主IPC或日志。

模块不可用、应用流转关闭、原生模式或交接准备失败时继续原翻译；AI已接管后错误不改发另一服务。冻结本体不提供本机/AI替换翻译，不将密钥发布给system维持运行。LSPosed仍仅系统和传送门两个作用域。
