# taplusbridge 0.15.42：隐藏桌面图标

日期：2026-11-09（Asia/Shanghai）。范围见 [scope.md](scope.md)。

## 使用

在「概览 → 运行与授权」打开「隐藏模块应用图标」，默认关闭，即时保存到系统组件状态。隐藏后，从「LSPosed → 模块 → taplusbridge → 模块设置」进入相同设置页，关闭开关即可恢复。

开关只控制独立桌面入口。真实设置 Activity、模块应用及识图/链接等业务组件保持启用，现有按需运行与空闲退出规则继续生效。没有新增权限、常驻服务或周期任务，也不将图标状态写入系统手势/规则快照。

## 实现与回归

- Manifest 将 MAIN/LAUNCHER 从 MainActivity 移到其后声明的 LauncherAlias，alias 默认 enabled、exported，target 为 MainActivity。
- 真实 MainActivity 保留 MAIN + `de.robv.android.xposed.category.MODULE_SETTINGS`。LSPosed 官方 AppHelper.getSettingsIntent 优先解析这一组合；固定参考提交 `df74d83eb03a44cc6ad268841ac2ada28d077c77`，路径 `app/src/main/java/org/lsposed/manager/adapters/AppHelper.java:43-92`。
- SettingsController 使用 PackageManager 的真实组件状态生成 Snapshot；切换仅对 alias 调用 setComponentEnabledSetting，并带 DONT_KILL_APP。没有重复的偏好布尔值，也不禁用整个应用或 MainActivity。
- Miuix Switch 复用现有样式，明确提供开启/关闭语义和恢复说明。
- 先跑红的 5 项后端用例覆盖独立 Manifest 入口、隐藏/恢复、PM 状态重读、业务组件及设置仍可解析、配置身份不变；新增 UI 回归覆盖默认关闭、开启、重开仍开启和关闭恢复。
- 本地渲染图为 `artifacts/release-0.15.42/ui-0.15.42/runtime-launcher-hidden.png`，已目视检查说明和开关布局；该图不是手机截图。
