# 0.14.6 / 31：完全匹配控件识别

日期：2026-11-02（Asia/Shanghai）。用户反馈 0.14.5 中完全匹配页重复 Google 控件仍可见，而其他模式正常。本版扩展识别逻辑并构建本地 R8 Release。延续用户此前要求，不运行回归测试或操作手机；未远程发布。

## 原因与修正

0.14.5 要求重复标签来自 `button`、链接或 ARIA 角色控件，并要求最近共同容器高度不超过 220px。Google 完全匹配页实际使用的普通容器未命中该选择器，因而旧模式栏保留；另外，脚本还把 URL 必须保留 `udm=48` 当作启用条件，Google 重定向去掉此参数时也会跳过处理。

0.14.6 直接检查可见、短文本的 `nav`、`tablist`、`section`、`div` 和 `form` 容器，寻找包含至少三个模式标签且呈横向短栏的最小容器；搜索控件按「添加更多搜索条件」等页面文字作同类定位。DOM 更新仍由节流后的 MutationObserver 重新处理。页面正文和 Google 的真实结果状态不隐藏；打开「原网页」时仍还原完整 Google 控件。
