# taplusbridge 0.15.43

- 改善长按识别与拖动后续动作的响应。复制、翻译及无需取链的场景不再额外等待；实际取链中的分享、规则和浏览器操作仍等待结果，明确结束后及时继续。
- 复用有效规则解析与单次展示策略，减少重复读取；配置提交失败时恢复已确认值，避免未保存设置被发布为活动配置。
- 为截图管道增加总时限与取消清理，慢读移出手势锁；合并拖动 MOVE 请求并保留触边和结束事件顺序。
- 隔离 Lens 会话文件，取消旧页面缩略图任务并限制总耗时；应用列表按需加载，可见图标异步缓存。
- 将完整诊断工具测试纳入 CI。没有增加权限、后台服务或第三方依赖。

版本为 **0.15.43 / 75**，继续使用原长期签名。覆盖安装后请重启，保持模块及传送门／系统框架作用域启用，再打开模块等待系统确认配置。

详细实现见 [长按响应优化](2026-11-09-gesture-latency.md) 和 [全项目优化](2026-11-09-project-optimization.md)，产物与本地验证见 [正式构建记录](2026-11-09-release-0.15.43.md)。实际设备响应、ROM 触摸交接、LSPosed 回调及真实服务仍需手机验收。
