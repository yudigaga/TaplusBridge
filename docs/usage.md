# 使用指南

适用于 TaplusBridge **0.15.50 / 82**。首次安装、宿主版本及构建方法见[项目首页](../README.md)，累计更新见[0.15.50 更新说明](release-notes-0.15.50-release.md)。

## 安装、作用域与恢复入口

在支持 libxposed API 102 的 LSPosed 中启用模块，勾选「传送门／内容扩展」`com.miui.contentextension` 和「系统框架」`system`，安装或更新后重启。支持的宿主为 4.1.3 / 40013、5.1.5 / 50015；AES 采集组件的版本不等于传送门宿主版本。

打开模块，在「概览 → 运行与授权 → 系统配置同步」确认「系统已确认配置」。本地保存成功不等于系统已应用；状态尚未确认时可点同步重试。该状态不包括 Lens 会话验收。

普通宿主识别、截图、补点、方向拖动和识别后的菜单协调使用上述两个作用域。若还需要替换**来源应用自己的原生选字工具条**，必须额外勾选该来源应用，保持模块来源名单允许它，并结束后重新启动来源应用；只勾选目标浏览器或翻译应用不能替代来源作用域。

「概览 → 运行与授权」可以隐藏桌面图标。隐藏后从 **LSPosed → TaplusBridge → 模块设置**进入同一页面恢复。模块本体需要保持启用且可运行；隐藏图标不会冻结或禁用本体。

## 设置页面与保存

| 页面 | 内容 | 保存方式 |
| --- | --- | --- |
| 概览 | 应用流转、已保存状态、运行与授权、关于与日志 | 流转及运行设置即时保存 |
| 识别 | 来源通道、图片与识图、替换翻译、默认浏览器、补点、长按与拖动 | 通道与开关即时保存；浏览器和翻译各自在弹窗保存；手势使用「保存手势」 |
| 应用 | 来源黑白名单 | 「保存名单」；「放弃名单」恢复已保存内容 |
| 规则 | 打开行为、目标应用、域名与协议规则、导入导出及在线规则 | 开关即时保存，规则编辑器单独保存 |

手势弹窗的「完成」或返回只收起弹窗并保留草稿，修改方向、计时或分享目标后仍需「保存手势」。放弃手势不撤销已经即时保存的识别开关，也不撤销单独保存的浏览器与翻译设置。

概览的「应用流转」控制模块打开、系统采集、补点、拖动与替换翻译；关闭后，传送门原有识别和独立 Lens 仍可能运行。「模块识别增强」也不是全部宿主识别的总开关。

## 来源应用与打开规则

「应用」页决定哪些来源应用可触发。黑名单中的应用禁止，白名单仅允许所选应用；两份名单独立保留，仅当前模式生效。空黑名单允许所有应用，空白名单全部禁止。首次保存前沿用传送门原设置，保存后个别来源应用可能需重新进入以刷新系统缓存。

名单接管后不再叠加宿主旧应用、Activity 和触点区域黑名单；宿主总开关、实际手势及系统安全与抓取限制仍有效。名单由主用户统一管理。

「规则」页决定链接交给哪个目标。规则里的来源约束只限制该条规则，不替代全局来源名单。为目标添加域名、网址或协议并保存，无需为每个目标编写专门适配；实际打开能力仍取决于目标应用声明和处理的入口。

磁力使用 `magnet:`，电驴使用 `ed2k:`。多链接可多选、全选并按目标分组；目标不支持批量时会提供显式复制。115 的受支持批次一次进入离线添加页，默认用户已经登录，实际登录失效和任务提交仍由目标应用及用户处理。

冻结目标可在「运行与授权」选择 Root 或 Shizuku 并取得对应授权。解冻目标与冻结模块本体是两件事；模块已移除冻结本体后继续运行的专用通道。

## 识别通道、截图与补点

「识别 → 识别增强与来源」提供六项独立选择：原生文字与卡片、页面结构采集、图片文字 OCR、服务端推荐识别、文字分词处理、剪贴板识别。分词处理已有文字，本身不是新的取链来源；剪贴板通道处理传送门本次收到的内容，不读取其他历史剪贴板。

页面结构通道读取触点附近的真实文字、链接及符合限制的叶节点内容描述，不点击来源。无法从来源未提供的标题还原隐藏地址；不会执行未知 ClickableSpan 来猜链接。

「图片与识图 → 截图采集兜底」在原生取数不足时提供当前来源图片，默认关闭，要求 Android 13+ 主用户；锁屏、安全窗口、可见输入法等限制保留。截图、OCR、Lens 各有独立设置，已有原生图片不依赖截图开关。

「补点取链 → 不可见点击取链」默认关闭。开启后，缺少真实链接时，可在达到识别阶段并松手后补点最初按下位置，拦截实际 HTTP(S) 启动地址并加入本轮结果；已有有效原生链接时跳过补点。原文、图片和链接共同保留。

补点会操作来源内容，请对确定会打开链接的入口使用；普通按钮可能执行原操作。应用内 JS／Compose 导航、PendingIntent、未覆盖的启动入口、菜单遮挡等仍可能无法取链。点击已送达或出现内容选择页，不代表已经取得网址或打开浏览器。

0.15.44–0.15.49 改善弹层长按、取链仲裁、有界父卡片 href、URLSpan 与叶节点描述读取，但没有保证评论区、帖子详情、信息流中每个入口都能取链。整张帖子卡片与卡片中的具体网页入口也可能执行不同导航。

## 长按与四方向拖动

在「识别 → 长按与拖动」启用功能，设置阶段计时、方向动作和分享菜单，然后点击「保存手势」。功能默认关闭，识别延迟和拖动延迟默认各 2000 毫秒，可分别设置为 100–10000 毫秒。

三个阶段都以同一次按下为起点累计：

| 阶段 | 到达时间 |
| --- | --- |
| 系统原生长按 | 系统长按时长 |
| 模块识别 | 系统长按时长 ＋ 识别延迟 |
| 方向拖动 | 系统长按时长 ＋ 识别延迟 ＋ 拖动延迟 |

例如系统长按设为 2 秒、两项延迟均为默认 2 秒时，阶段约为按下后 2、4、6 秒。识别延迟同样用于普通长按识别／补点，关闭拖动后仍生效；拖动延迟只在拖动开启时使用。OCR、分词、网络和目标解冻等后续工作不包含在这张计时表中，阶段到达不保证动作立即完成。

原生长按回调照常执行，提前松手留给系统菜单。到识别截止时单震提示；拖动遮罩真正接管后双震提示。进入拖动后，拖向屏幕上、下、左、右边缘并松手执行对应预设；回中央、返回或取消则不执行新增方向动作。遮罩接管后，其他手势保持屏蔽到松手或取消。

默认上方为模块能力菜单、下方为分享、左方为识图、右方为翻译。每个方向均可改为菜单、分享、浏览器、规则打开、识图、翻译、复制或不执行。

原文、OCR 文字、图片、链接属于不同内容类型；只有一种时直接执行，多种时选择本次使用的内容，不重新选择方向动作。多个链接算一种，分享和传送门可全部使用，浏览器和规则打开仍需选择其中一个。分享菜单可显示全部可用目标，或按所选目标及顺序显示；选择「只显示所选目标」却未选择目标时不会自动回退为全部。

0.15.50 在 OCR、分词满足完成条件且本轮已有有效链接时，使用交付瞬间捕获的有效链接继续动作，不等待在线任务新增的附加推荐，也不把晚到推荐追写到已经开始的动作。没有有效链接的卡片继续保留当前推荐及补点的必要等待。因此这项优化不代表所有场景的等待都已消除。

系统全局拖拽入口还要求来源应用提供真实拖拽；模块方向入口复用系统／宿主本轮采集。相关手势限主用户、主显示器。图片有界读取，最大 8 MiB，采样长边不超过 2000、总像素不超过 300 万；模块不额外下载远程图片。

## 默认浏览器与原生选字工具条

在「识别 → 默认浏览器」指定浏览器并保存。选择「沿用原选择」可恢复系统默认或原候选逻辑。拖动的浏览器动作，以及普通网页识别未命中规则时的网页兜底，使用所选浏览器；已命中的域名／协议规则和非浏览器原生入口保留原优先级。指定目标卸载或不可用时会提示重新选择，不静默改开其他浏览器。

来源工具条需要前述额外来源作用域。接管保留系统工具条外观、全选、复制、问小爱等原操作，只替换可识别的浏览器／翻译项；缺少对应项时按有效选区增加入口。浏览器仅处理完整 HTTP(S) 地址、唯一有效 URLSpan 或原网页动作中的真实 URL，不把普通词当网址。

覆盖范围为**原生、非编辑、非密码、非安全窗口的 TextView 浮动 ActionMode**。WebView、Compose、自绘菜单和其他自定义选区不保证覆盖；平台菜单 Hook 安装失败时保留原工具条。来源工具条的翻译替换仅支持「本机翻译应用」模式，沿用宿主及 AI 模式不接管来源翻译菜单。宿主翻译卡片和拖动翻译不受这项来源工具条范围说明替代。

0.15.47／0.15.48 的菜单协调另在识别卡实际显示后尝试关闭本轮新出现的菜单，并保留识别内容与长按前已有窗口；只使用系统框架和宿主作用域。无法识别的自绘菜单或无法验证的回声仍可能保留，真实手机效果尚需验收。它没有解决所有此前报告的帖子取链或来源翻译问题。

## 替换翻译

入口：「识别 → 替换翻译」，在弹窗内保存。宿主翻译按钮、翻译卡片和拖动翻译共用设置。

- **沿用传送门翻译**：保留宿主流程。
- **本机翻译应用**：选择应用声明的专用翻译、文字处理或分享入口。分享兼容只承诺交付文字，实际翻译页面与目标语言由目标应用决定；入口失效时提示重新选择。
- **AI 翻译**：填写完整 HTTPS Chat Completions 接口地址、API Key、模型、目标语言及可选提示词。接口不会自动追加路径。「测试连接」发送固定测试句，不保存草稿或发送当前选中文字；结果页支持复制与显式重试，失败不自动改发其他服务。

宿主的 APP 模式翻译卡显示所选应用图标，AI 模式显示模块图标，原生模式保留宿主图标。模块不可用或交接前条件不满足时保留原宿主流程；已经进入 AI 结果页后的服务失败在该页提示。

API Key 和完整配置保存在本体私有存储，不交给系统快照、宿主或日志。只有图片而没有文字时仍依赖宿主 OCR 链路。正文上限 32768 字符，AI 网络总期限 30 秒，无自动重试。更多设置说明见[翻译说明](2026-11-06-translation-usage.md)，其中冻结本体相关历史描述应以本指南的当前运行方式为准。

## Google Lens 与后台运行

「识别 → 图片与识图 → Google Lens 识图」默认开启。点击识图才上传选中图片，未点击前保留宿主原图片面板；关闭开关恢复宿主识物操作。需要可访问 Google 的网络及可运行的模块本体，不使用付费 API、自建服务器或图床。

结果页支持「AI 模式／全部／完全匹配／外观匹配」。搜索和切换模式复用本轮 Google 图片会话，不再次上传；Android 11+ 可显示同会话的 AI／完全匹配内容，Android 9／10 可使用「原网页」入口。临时图片会话不能交给外部浏览器，也不复制 Chrome／Google App 登录 Cookie。只有确认遇到 Google 验证页时才提供处理入口，解析失败不等于需要登录。

本体主进程和 `:lens` 工作进程按需启动。界面关闭、任务完成、服务解绑及待交付内容释放后，空闲约 3 秒退出；活动 Lens 会话、翻译、解冻、文件选择和设置保存期间保留任务。系统和宿主中的必要 Hook 持续监听。图片分享的短期只读授权可在模块进程重建后使用，仍受有效期限制。

## 失败排查与验证边界

先确认安装版本、重启后的 LSPosed 加载版本、来源作用域、应用名单和「系统已确认配置」，再检查所需的通道、截图和补点开关。来源工具条问题需要检查来源进程是否安装 Hook，系统进程的安装消息不能代替来源进程证据。

复现后可在 LSPosed 导出模块日志，标签为 `TaplusBridge`；模块记录固定处理阶段及失败原因，不记录正文或完整链接。同一次操作的识别、补点、导入、选择和真实启动需要分开判断。

本地单元测试和静态宿主检查不等于真实 ROM、触摸转移、LSPosed 回调、来源应用点击、Google／AI 服务、Root／Shizuku 或目标应用服务验收。已知边界与历史诊断见[文档索引](README.md)，本版产物证据见[构建与发布验证](2026-11-13-release-0.15.50.md)。
