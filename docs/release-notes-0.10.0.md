# taplusbridge 0.10.0

- 新增「截图识别兜底」独立开关，默认关闭，位于「生效应用」页，与名单一起保存。
- 为原生无法取数的允许应用增加系统侧真实长按截图入口；松开后交给传送门原有回调、OCR 和浮窗流程，不注入来源进程。
- 保留锁屏、安全窗口和可见输入法限制，核验同一前台主窗口，原生已成功开始识别时抑制重复兜底。
- 截图通过限量、限时、一次性的内存管道交付，仅真实宿主可领取；关闭开关或配置变化会阻止旧请求继续交付。
- 窗口截图不作为卡片区域，不据此模拟点击来源页面。
- 修复白名单枚举把 `android` 等合法单段平台包误当非法，导致整份白名单发布失败的问题；目标启动和解冻包名校验不放宽。
- 按用户要求，最终版本只构建并检查签名/对齐，未运行最终全量测试、完整Lint或真机验收。
