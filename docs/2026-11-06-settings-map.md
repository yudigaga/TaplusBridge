# 设置归属与逻辑核对

本轮按0.15.34代码核对配置键、调用者和保存方式。设置位置变化不迁移或重置配置，不修改识别/取链运行链路。

## 导航

| 主入口 | 职责 | 操作方式 |
|---|---|---|
| 概览 | 应用流转、已保存状态、运行授权和关于日志 | 流转开关即时保存；其余编辑集中于弹窗 |
| 识别 | 来源、图片、补点、长按与拖动 | 四个分组弹窗；识别开关即时保存，手势草稿单独保存 |
| 应用 | 哪些来源应用可触发 | 主页仅已选名单，添加弹窗搜索；保存名单或放弃名单 |
| 规则 | 链接交给哪个应用 | 打开行为、规则列表、规则管理；规则编辑显式保存 |

来源应用与规则目标应用用途不同。应用页控制全局来源范围；规则来源仅约束该条域名匹配，规则目标决定打开应用，不应与来源名单合并。

## 逐项归属

| 配置或设置 | 唯一编辑位置 | 实际作用与边界 | 保存方式 |
|---|---|---|---|
| `enabled` | 概览／应用流转 | 模块打开、系统采集、补点和拖动；不停止应用原有识别或独立Lens | 即时 |
| `recognition` | 识别／识别增强与来源 | 链接补充和宿主来源过滤；关闭时宿主识别仍可能执行 | 即时 |
| `recognition_channels.native` | 同上 | 原生正文、卡片及外部拖入来源；并非原生目标打开开关 | 即时 |
| `recognition_channels.assist` | 同上 | 触点附近页面结构，需要流转、增强及允许的来源范围；不点击来源 | 即时 |
| `recognition_channels.ocr` | 同上 | 从已有图片识别正文和网址；不等于截图或Lens开关 | 即时 |
| `recognition_channels.server` | 同上 | 宿主服务端推荐；不禁止OCR自身云路径 | 即时 |
| `recognition_channels.segment` | 同上 | 对已有文字分词，不是新增取链来源 | 即时 |
| `recognition_channels.clipboard` | 同上 | 宿主本次收到的剪贴板；不读取历史剪贴板 | 即时 |
| `scope_capture_fallback` | 识别／图片与识图 | 提供系统长按/拖动来源图片；已有原生图片仍可用 | 即时 |
| `google_lens` | 同上 | 点击识图后上传选中图片到Google；需要本体与网络 | 即时 |
| `scope_link_probe` | 识别／补点取链 | 允许松手后补点最初触点以获取实际启动链接；会操作来源内容 | 即时 |
| `capture` | 同上／微信QQ原生卡片补点适配 | 原宿主卡片适配；依赖流转、增强、补点。不是所有卡片静默识别，也不控制截图 | 即时 |
| `drag_settings.enabled` | 识别／长按与拖动 | 模块方向拖动；不要求增强开关开启，仍受流转与来源范围影响 | 保存手势 |
| `recognitionDelayMillis` | 同上／阶段计时 | 普通长按识别/补点也使用，拖动关闭时仍可调整 | 保存手势 |
| `dragDelayMillis` | 同上／阶段计时 | 进入拖动的追加阶段延迟 | 保存手势 |
| 四方向动作 | 同上／方向动作 | 各方向独立；拖动启用后显示 | 保存手势 |
| 分享模式、目标和顺序 | 同上／分享菜单 | 只选模式显示搜索和已选排序；空名单不自动退回全目标 | 保存手势 |
| 来源黑白名单 | 应用 | 两份名单保留，仅当前模式生效；已选未安装记录可移除 | 保存名单 |
| `native` | 规则／打开行为 | 规则未命中时接管宿主原生目标；不影响已命中域名规则 | 即时 |
| 规则目标启停 | 规则／目标条目 | 仅控制相应目标参与路由；不是来源应用范围 | 即时 |
| 单条规则来源、域名、目标、备注 | 规则编辑器 | 手动优先；匹配预览不执行打开或解冻 | 编辑器保存 |
| 在线更新许可 | 规则／规则管理／在线规则 | 禁止更新后保留已校验缓存；同步、导入、导出、清空各有独立动作 | 即时或显式操作 |
| `independent_runtime` | 概览／运行与授权 | 本体不可用时的独立打开，不承诺Lens或全部后台功能 | 即时 |
| `engine`与授权检查/请求 | 同上 | Root/Shizuku方式与当前方式授权就近显示；选择方式不自动请求权限 | 选择即时，授权显式操作 |

增强关闭不是全部识别来源的电源：宿主OCR/推荐可能照常，模块外部拖入及部分系统采集仍读取保存的来源选择。因此六来源保持可编辑，不隐藏或清零；图片组明确这一点。补点适配则在补点关闭时隐藏，增强/流转关闭时禁用并保留原值。

## 去重与修正

Lens删除概览编辑入口，仅保留只读摘要，编辑集中在图片弹窗。全配置监听使概览摘要随已保存值变化，手势未保存草稿不会伪装成已生效状态。

旧“原生链接接管”改名“原生目标兜底”并归规则；旧“自动识别分享卡片”改为实际的微信/QQ原生卡片补点适配，并集中到补点弹窗。截图、OCR、Lens继续独立，系统同步状态注明不包括Lens。

解冻方式与对应授权操作归同一弹窗；关于只展示版本及日志入口。规则工具收进管理弹窗。应用名单成功保存后重新读取接管/损坏状态，修复已保存却继续显示首次接管或损坏提示的问题。

弹窗完成或返回只收起并保留草稿；顶部明确“保存手势／放弃手势”和“保存名单／放弃名单”。规则目标开关、在线更新、识别及运行开关均即时生效，未强行统一成草稿。
