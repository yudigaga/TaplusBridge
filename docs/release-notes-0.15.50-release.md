# taplusbridge 0.15.50

正式版 **0.15.50 / 82**。本次从远端 0.15.43 升级，合并其后各轮本地候选的变更。

- 改善长按拖动后的打开、分享响应：本轮已有有效链接时不再等待在线附加推荐；无有效链接时仍保留必要等待，OCR、分词与三个手势阶段时间不变。
- 修正弹层及社交页面取链的窗口判断、触点与补点仲裁；识别界面出现后协调关闭来源菜单，并针对菜单退出回声保留本轮识别任务。
- 增加独立浏览器设置，统一浏览器和翻译目标选择；提供受条件约束的来源原生选字工具条接管。该入口需要额外勾选来源应用作用域，范围和限制见使用指南。
- Assist 正文为空时，允许合格的叶节点内容描述作为回退；分享目标在后台构建，修复图片缓存时间早于授权起点的问题。
- 整理项目首页、使用指南和技术文档索引，保留赞助入口与旧版技术记录。

## 安装与使用

覆盖安装后重启，在 LSPosed 保持传送门／内容扩展和系统框架作用域启用，再打开模块确认系统已同步配置。仅使用模块识别与菜单协调时不需勾选所有来源应用；原生选字工具条的浏览器／APP 翻译接管需额外勾选对应来源应用并重启该应用。

已有有效链接时会交付当前快照，动作开始后不再追写在线服务晚到的附加推荐。无法从应用实际提供的正文、图片、描述或启动意图中取得的隐藏链接，不保证能够还原。

详见 [使用指南](usage.md)、[文档索引](README.md) 与 [构建和发布核验](2026-11-13-release-0.15.50.md)。手机上的 LSPosed 回调、ROM 菜单交接及实际响应时间仍需设备验收。
