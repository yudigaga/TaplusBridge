# taplusbridge 0.15.42

- 在「概览 → 运行与授权」增加「隐藏模块应用图标」，默认关闭，切换立即生效。
- 仅控制独立桌面入口，不禁用模块应用、设置页或业务组件，也不增加后台任务。
- 隐藏后可从「LSPosed → 模块 → taplusbridge → 模块设置」重新进入，关闭开关恢复图标。
- 包含 0.15.41 的按需运行调整：移除“冻结本体后继续运行”通道，模块保持启用；界面、任务、绑定和待交付内容全部结束后，空闲约 3 秒退出自身进程。
- 保留识图、翻译、解冻及编辑中的任务保护，分享图片授权支持模块进程重建后读取。

覆盖安装后请重启，保持模块及作用域启用，打开模块等待系统确认配置。图标状态由系统包管理保存，应用重启后仍保留。不同桌面的图标刷新时机可能不同，实机显示与 LSPosed 分支仍需手机验收；本地验证见 [构建记录](2026-11-09-release-0.15.42.md)。
